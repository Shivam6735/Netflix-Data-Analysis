Netflix Data Analysis Project
Tools Used: Python, Pandas, Matplotlib, Seaborn

Project Overview
Performed exploratory data analysis on a Netflix movie dataset to uncover trends in genres, popularity, ratings, and yearly movie production.

Key Analysis & Findings
1. Most Frequent Movie Genre
Analyzed the frequency of genres in the dataset to identify which type of movies are most commonly released on Netflix.

Insight:
The Drama genre appeared most frequently, indicating that Netflix strongly focuses on storytelling-driven content.

2. Movie with the Highest Vote Average
Identified the movie with the highest value in the vote_average column to determine the top-rated film based on audience ratings.

Insight:
The movie with the highest vote average achieved the best audience rating among all titles in the dataset.

3. Most Popular Movie and Its Genre
Examined the popularity metric to determine which movie generated the highest engagement and visibility.

Insight:
The movie with the highest popularity belonged to the Action genre, suggesting that action films tend to attract larger audience attention.

4. Year with the Highest Number of Movie Releases
Analyzed movie release years to find which year had the maximum number of films produced.

Insight:
The dataset shows a peak in movie releases in one specific year, indicating a significant increase in content production during that period.
